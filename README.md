# SafeTrail

SafeTrail — мобильное приложение для планирования безопасных маршрутов
в лесных массивах, разрабатываемое в рамках курсового проекта.

Приложение строит пеший маршрут от точки А до точки Б с учётом факторов
безопасности.

## Возможности

- построение маршрута по карта;
- отображение зон с опасностями;
- офлайн-режим;
- метрики маршрута.
