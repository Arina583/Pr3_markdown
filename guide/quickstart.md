# Первый маршрут

## Построение маршрута

1. На главном экране нажмите **Построить маршрут**.
2. Укажите начальную и конечную точки: длинным нажатием на карту
   или через поиск по названию населённого пункта.
3. Выберите профиль безопасности:

| Профиль    | Логика построения                              |
| ---------- | ---------------------------------------------- |
| Быстрый    | кратчайший путь без учёта опасных участков     |
| Безопасный | обход зон без связи и безлюдных участков       |

4. Нажмите **Сохранить маршрут** — он будет сохранён в офлайн-кэш.

## Офлайн-режим

Перед выходом в лес откройте построенный маршрут и включите
переключатель **Офлайн**. Приложение загрузит карту района и схему
маршрута в локальное хранилище. После потери связи навигация
продолжит работу по кэшу.

## Тревожная кнопка SOS

Длинное нажатие кнопки SOS отправляет SMS с текущими координатами
и ссылкой на карту доверенным контактам. Сообщение формируется
на устройстве и не требует мобильного интернета.

## Пример планируемого запроса к сервису маршрутизации

Модуль планирования обращается к backend-сервису по контракту,
описанному в разделе [Обзор API](../api/overview.md). Планируемая
реализация на Kotlin:

```kotlin
val body = RouteRequest(
    start = GeoPoint(56.1290, 40.4070),
    end = GeoPoint(56.1450, 40.3910),
    profile = "safe"
)
val route = api.planRoute(body)
mapView.drawPolyline(route.points)
```
