# Демонстрация элементов разметки

Справочная страница документации SafeTrail, на которой показаны
все обязательные элементы варианта задания.

## Подчёркнутый текст

В SafeTrail <u>зоны без мобильной связи</u> выделяются на карте
красной заливкой, а <u>участки маршрута с устойчивым покрытием
сети</u> — зелёной.

## Блок кода

Пример тела запроса к сервису построения маршрута:

```json
{
  "start": [56.1290, 40.4070],
  "end": [56.1450, 40.3910],
  "profile": "safe",
  "offline_cache": true
}
```
