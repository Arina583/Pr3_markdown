# Демонстрация элементов разметки

Справочная страница документации SafeTrail, на которой показаны
все обязательные элементы варианта задания для выполнения практической работы.

## Подчёркнутый текст

В SafeTrail <u>зоны с опасными участками</u> выделяются на карте
красной заливкой, а <u>участки маршрута без опасных участков</u> — не имеют цветового окраса.

## Блок кода

Пример тела запроса к сервису построения маршрута:

```json
{
  "start": [56.1290, 40.4070],
  "end": [56.1450, 40.3910],
  "profile": "safe",
  "offline_cache": true
}
```
