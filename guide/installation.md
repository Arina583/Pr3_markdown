# Установка

## Требования

| Компонент            | Значение             |
| -------------------- | -------------------- |
| Операционная система | Android 7.0 (API 24) и выше |
| Разрешения приложения| геолокация           |

## Сборка из исходного кода

Проект реализован на Kotlin:

```bash
git clone https://github.com/Arina583/MobileApp.git
cd safetrail-app
./gradlew assembleDebug
```

Установите приложение на устройство
и запустите приложение.

## Первый запуск

При первом запуске приложение запросит разрешение на определение
геолокации — оно необходимо для построения маршрута от текущей точки.
