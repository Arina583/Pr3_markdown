# Установка

## Требования

| Компонент            | Значение                  |
| -------------------- | ------------------------- |
| Операционная система | Android 7.0 (API 24) и выше |
| Разрешения приложения| геолокация, SMS           |

## Сборка из исходного кода

Проект реализован на Kotlin:

```bash
git clone https://github.com/ВАШ-ЛОГИН/safetrail-app.git
cd safetrail-app
./gradlew assembleDebug
```

Собранный APK появится в каталоге
`app/build/outputs/apk/debug/`. Установите его на устройство
и запустите приложение.

## Первый запуск

При первом запуске приложение запросит разрешение на определение
геолокации — оно необходимо для построения маршрута от текущей точки.
Без разрешения доступен только режим планирования от произвольных точек.

> Рекомендуется заранее скачать офлайн-карту района похода: покрытие
> мобильной сети в глубине лесного массива отсутствует. Настройка
> офлайн-режима описана в разделе [Первый маршрут](quickstart.md).
