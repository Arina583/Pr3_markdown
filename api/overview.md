# Обзор API

Backend-сервис SafeTrail (проектируется в рамках курсового проекта)
предоставляет REST API для построения маршрутов и получения сведений
о зонах риска.

## Базовый адрес

```
https://api.safetrail.example/v1
```

## Формат данных

Запросы и ответы передаются в формате JSON, кодировка UTF-8.

## Аутентификация

Каждый запрос должен содержать заголовок:

```
Authorization: Bearer <token>
```

## Формат ошибок

При ошибке сервис возвращает объект с полями `error` и `message`:

```json
{
  "error": "route_not_found",
  "message": "Не удалось построить маршрут между указанными точками"
}
```

Перечень эндпоинтов — в разделе [Список методов](endpoints.md).
