# Список методов

| Метод | Путь                 | Назначение                                  |
| ----- | -------------------- | ------------------------------------------- |
| POST  | `/routes/plan`       | построение маршрута с заданным профилем     |
| GET   | `/routes/{id}`       | получение сохранённого маршрута             |
| GET   | `/hazards`           | зоны без связи и опасные участки в области  |
| POST  | `/trips`             | регистрация похода с контрольными точками   |
| GET   | `/trips/{id}/status` | статус прохождения маршрута                 |

## Пример: построение маршрута

**Запрос** `POST /routes/plan`

```json
{
  "start": [56.1290, 40.4070],
  "end": [56.1450, 40.3910],
  "profile": "safe"
}
```

**Ответ**

```json
{
  "route_id": "r-1024",
  "distance_km": 7.4,
  "est_time_min": 118,
  "hazards_on_route": 1,
  "points": [[56.1290, 40.4070], [56.1312, 40.4051]]
}
```

## Пример: зоны риска

**Запрос** `GET /hazards?bbox=40.39,56.12,40.42,56.15`

```json
{
  "hazards": [
    {
      "id": "h-77",
      "type": "no_signal",
      "center": [56.1380, 40.3990],
      "radius_m": 900
    }
  ]
}
```
